# Task Done - Requirements Analysis

## Description:    
The requirements of the website are:      

### Application
The application can:
- manage the tasks (show, add, edit, viewing details, delete)
- create the users with admin (super user)
- search the tasks
- filter tasks by (only users' tasks)   

### User   
User can:
- login
- create tasks
- edit task
- view details
- delete task
- see other users' tasks and their details   

### UI/UX
The UI/UX need to be:
- some simple with less complexity
- not to make the user confused
- modern UI UX and beautiful
- responsive design    

### Pages
the pages are:
- home (the main page)
- workplace (for seeing and managing tasks)
- about (explaining about the website)
- add (adding tasks)
- edit (editing tasks)
- details (seeing tasks' details)
- delete (deleting tasks)   

### Security
The website security is:
- users can only login (no registrating)
- only users can access to workplace page and see tasks
- all users have permissions to see all tasks
- only users who created the tasks can edit or delete it.
- pages need to connect to the back-end safe and secure.   

### Technically
The application: 
- faster response
- using APIs to connecting to different devices
- maintainable
- secure
- scailable
- limit in server deployment
