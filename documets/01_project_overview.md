# Task Done - Project Overview

## Description    

Task Done is a task management web application built using Django and Django REST Framework.    
In this web application, you can manage your tasks(like add, edit, view its details, and delete) them. You can also see other users' tasks.
The web application has two sides: front-end which developed with **HTMl**, **CSS**, and **JavaScript**,  
and back-end which developed with **Python Django** framework and **Djanog REST Framework**.
The goal of this project was to design a scalable task management system with separation between frontend presentation and backend services
as a learning practice website.  

## Main Features  
The features of this web application are:  

- User authentication
- Task creation
- Task editing
- Task deletion
- Task filtering
- Task status management
- REST API support
- Permission management
